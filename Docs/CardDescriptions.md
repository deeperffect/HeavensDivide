# Card descriptions

`Tools/card_descriptions.json` is the player-facing copy catalog for all 108 saved upgrades. Entries contain a display name, description, rolled rarity format, and optional rarity-specific wording. Stable IDs and asset names remain unchanged. All six route starters use the `Stance` suffix in their display names.

Run `Tools/publish_upgrade_copy.py` with Unreal's Python commandlet after gameplay authoring. `Tools/configure_card_descriptions.py` and the non-audit path of `Tools/shorten_samurai_descriptions.py` forward to it. Publication updates only display names and description fields, including rarity overrides. Backups live under `Saved/Backups/CardDescriptions`; complete serialized comparisons verify every non-copy property. Pool, UI, and artwork files are protected by hashes.

Names are limited to 30 characters and descriptions to 220. This is an editorial budget, not a pixel-perfect layout test. Copy leads with the effect and retains meaningful trigger conditions, values, drawbacks, and upgrade conversions. Development notes, internal units, repeated rank limits, and implementation terminology do not appear on cards. Chance increases use compact `+X% chance` wording for additive percentage-point bonuses. Slow and vulnerability improvements say `additional X%`. Rolled descriptions retain the actual rarity magnitude; Multiple Strikes uses singular/plural overrides.

Run `Tools/validate_production_upgrade_copy.py` in a fresh process to verify all saved names, descriptions, rarity variants, and preserved properties without modifying assets. This standalone validator contains no asset setters or package saves. `Tools/configure_card_descriptions.py -ValidateCardDescriptions` also routes to it. Reports are written to `Saved/CardDescriptionsChanges.json` and `Saved/CardDescriptionsValidation.json`.

Publication also refreshes the artwork manifest's copy and its preservation baseline after verifying the copy-only change. Original image-generation prompts are retained. Run `Tools/build_upgrade_icon_gallery.py` to refresh the [card gallery](../Art/UpgradeIcons/index.html).

The gallery presents the 98 currently available upgrades with player-facing categories, names, effects, and artwork. Retired and disabled cards remain in the 108-asset copy catalog for maintenance but are omitted from the player-facing gallery. It does not expose stable IDs or asset paths. Preview the longest stance and synergy descriptions in the level-up menu after changing card fonts or layout. Reload externally changed assets or restart the editor before previewing, and repackage for packaged builds.
