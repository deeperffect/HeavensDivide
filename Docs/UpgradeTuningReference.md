# Upgrade runtime balance key reference

These are migration defaults, not a live export of your edited assets. Values on the saved Upgrade Data Assets are authoritative. Distances are centimeters, timing is seconds, angles are degrees, and multipliers use 1 = 100%. Counts are rounded. See [UpgradeTuning.md](UpgradeTuning.md) for the editing workflow and VFX contract.
